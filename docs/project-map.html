Sign-in end-to-end flow

From opening the app to entering the workspace—or returning to sign-in.

CURRENT FLOW
01

Open the app

AppController.start() checks the current browser-tab session.

02

Enter credentials

LoginView collects the Admin username and password.

03

Verify password

AuthenticationService checks the account using PasswordHasher.

04

Open overview

A valid sign-in starts a session and renders the DashboardView.

05

Sign out

The session is cleared and the controller returns to the login view.

Invalid credentials Stay on the login page, show an error, and allow another attempt.
Valid credentials Show the Admin dashboard for the current tab session.

This frontend-only login is a starter convenience gate, not secure access control. GitHub Pages exposes client code and stored hashes; use a trusted backend before handling private data.
